# Telegram Bio Protect & Auto Delete Bot

## Features
1. Auto Ban Users with Bio Links or Channel Handles (@)
2. Auto Delete Group Messages after set delay (Default: 60s)
3. Owner Command `/stats` (View added groups count)
4. Owner Command `/broadcast` (Send message/link/photo to all groups)

## Render Settings
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python main.py`
- **Environment Variable:** Set `PYTHON_VERSION` to `3.10.12`
